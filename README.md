# MinecraftTick

Minecraft 1.20.1 Forge 服务端 mod：无人（或全员挂机）时自动暂停游戏刻，有人活动时同刻恢复。

## 功能

- 服务器无人在线时冻结全部世界刻：天数、天气、生物、农作物、方块实体、刷怪全部停止，存档不走游戏刻
- 玩家加入后同刻以默认 20 TPS 恢复；最后一个玩家退出后同刻再次暂停
- **挂机检测**：在线玩家超过 `afkTimeoutSeconds` 秒没有任何移动、视角变化或交互，即视为"假离线"；全员假离线时同样暂停世界刻（挂机钓鱼不再让世界运转），任何玩家动一下立即同刻恢复
- **`/afk` 命令**：手动挂机
  - `/afk` 切换自己的挂机状态，`/afk on|off` 显式设置（所有玩家可用）
  - `/afk <玩家> on|off` 标记他人（OP，权限等级 2，控制台可用）
  - 手动挂机立即生效（不等待超时），玩家真实移动/交互或输入 `/afk off` 自动解除
- 挂机玩家聊天、点击方块/实体、打开容器都算活跃
- 不阻塞服务器主线程：玩家登录、列表查询、后台命令全程可用，看门狗不会误判；每刻照常自动存档

## 配置（config/tick-common.toml）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `pauseWhenEmpty` | `true` | 无人/全员挂机时暂停游戏刻 |
| `afkTimeoutSeconds` | `300` | 挂机判定秒数，`0` = 关闭挂机检测 |

## 后台日志

- 无人在线：`检测到服务器无人在线，已暂停游戏刻，世界天数停止推进`
- 全员挂机：`检测到在线玩家均已挂机超过 X 秒（视为假离线），已暂停游戏刻，世界天数停止推进`
- 全员手动挂机：`检测到在线玩家均已手动挂机（视为假离线），已暂停游戏刻，世界天数停止推进`
- 恢复：`检测到玩家 XXX 进入/恢复活动（当前在线 N 人），游戏天数继续运行，游戏刻已恢复`

## 实现说明

暂停通过清空 `MinecraftServer` 中 Forge 补丁缓存字段 `worldArray`（`tickChildren` 每刻遍历的世界数组）实现，这三个字段为 Forge 自加、开发与生产环境字段名一致。世界刻整体跳过但主循环、网络与任务处理照常运行；若反射失败会自动回退为原版行为。
